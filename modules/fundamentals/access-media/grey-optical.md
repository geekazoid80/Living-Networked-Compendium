## Scope (planned)

Once written, the reader will be able to:

1. **Distinguish** single-mode (1310/1550 nm) versus multi-mode (850 nm) optics by application and reach.
2. **Select** an appropriate grey-optical transceiver for a given link budget and distance requirement.
3. **Recognise** when grey optics suffice versus when coloured optics (CWDM / DWDM, see [AM-007](coloured-optical.md)) become necessary for fibre conservation.
4. **Interpret** transceiver diagnostic data (DDM / DOM: TX power, RX power, temperature) for first-line fault isolation.
